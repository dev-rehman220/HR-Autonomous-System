# Project Context & Domain Reference

## Organizational Context
- **Organization:** Engineering Division / Talent Acquisition Group.
- **Hiring Focus:** Mid-to-Senior Software Engineers, Data Engineers, and AI/ML Specialists.
- **Hiring Criteria:**
  - Technical competence in core stack (Python, TypeScript, Go, Cloud Native).
  - Production deployment experience vs. toy/academic projects.
  - Clear communication and structured documentation.

## Compensation Bands (Strict Context)
- Software Engineer II (L4): $110,000 - $140,000 USD
- Senior Software Engineer (L5): $145,000 - $185,000 USD
- Staff Software Engineer (L6): $190,000 - $235,000 USD
